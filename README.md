## 🤝 Contributing

This project is managed by Claude AI with human oversight.

### Process
1. **Task Assignment** → Task logged in CLAUDE.md
2. **Implementation** → Code changes made and tested
3. **Commit** → Changes committed with full context
4. **Documentation** → Task log updated with results
5. **Push** → Changes synced to GitHub

### Guidelines
- Follow commit message templates (see CLAUDE.md)
- Update CLAUDE.md after every task
- Test changes locally before pushing
- Keep GitHub in sync with local changes
